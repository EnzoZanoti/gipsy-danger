# gipsy-danger
A Batalha de Robôs – Modalidade Sumô tem como objetivo promover a aplicação prática dos conhecimentos de Lógica para Computação, envolvendo programação, eletrônica, criatividade, estratégia, trabalho em equipe e desenvolvimento de algoritmos. O objetivo de cada batalha é fazer com que o robô adversário saia completamente da arena.
